## Defects found in the initial audit and fixed

- Unchecked custom vehicles were displayed despite the GUI's inclusion field.
- Two Chapter 2 tables declared more columns than their headings and data used.
- Missing geometry could create an adjacent-girder pair that did not exist.
- Several local page breaks bypassed automatic table pagination.
- Chapter 4 inserted blank support-reaction rows despite supplied records.
- Malformed/nonfinite analysis values could crash or display `nan`; missing
  span produced zero allowances, and incomplete girder coverage could pass.
- Chapter 7 displayed raw invalid quantities while its chart correctly used N/A.
- Exactly-unity utilization bars were green, and check headings were crowded.
- A missing-figure caption exposed literal math markup instead of plain text.

The analysis guards preserve valid supplied values and the existing L/800 and
L/600 presentation comparisons. They are not a new bridge design method.
The designer, analyser, IRC routines and original BOQ calculator are unchanged.

## Reproduce the deliverables

From the full checkout, prepare the reporting environment and regenerate only
the enhanced PDF from the saved fixture:

```powershell
python scripts/setup_reports.py --with-compiler --dev
.\.venv\Scripts\python.exe run_report.py --input artifacts/demo/demo_input.json --output artifacts/demo --name Report_After --compiler .tools/tectonic.exe
```

This preserves the tracked baseline. To reproduce both rendering examples in
a separate location:

```powershell
.\.venv\Scripts\python.exe scripts/build_comparison.py --compiler .tools/tectonic.exe --output output/reproduced-comparison
```

Both are explicitly synthetic rendering fixtures. The original renderer's
baseline compiler errors and special continue-on-errors route remain disclosed
in `artifacts/demo/README.md`. These commands do not perform a GUI design.

Run the automated checks and real PDF matrix:

```powershell
$env:OSDAG_TEST_LATEX = "$PWD\.tools\tectonic.exe"
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/run_report_matrix.py --compiler .tools/tectonic.exe
```

The distribution test additionally needs `OSDAG_TEST_PACKAGE` pointing to a ZIP
from `scripts/package_reports.py`. See [validation.md](validation.md) for actual
executed results rather than assuming every optional check ran.
