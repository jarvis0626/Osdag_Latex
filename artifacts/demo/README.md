# Report rendering comparison

`Report_Before.pdf` and `Report_After.pdf` use the same **synthetic** fixture in
`demo_input.json`. These files demonstrate report behavior; no structural design
or GUI analysis was run. Deliberate failures appear in the fixture. They are not
construction documents or a completed official screening submission.

The baseline is generated by the unmodified report functions at upstream commit
`d74f56dd7f22925fb8148cabf5740ed8d1e39ff3`. Its LaTeX errors are intentionally
retained; the comparison harness uses Tectonic's continue-on-errors mode to
mirror the original renderer's nonstop compilation behavior. Only the original
pure result-alias helper is isolated from the solver dependency. No baseline
chapter templates or engineering values are repaired.

The enhanced report requires a successful compiler exit and valid PDF output.
Source and matching image assets are included so each report can be inspected
and rebuilt. Generated `.log` files remain local and are not committed.

The 18 November follow-up preserves the tracked original baseline byte for
byte and regenerates only the enhanced PDF from the existing saved fixture.
It records the updated checks and 33-page result in
[`artifacts/official_verification`](../official_verification/validation.json).

Reproduce from the repository root:

```powershell
.\.venv\Scripts\python.exe scripts/build_comparison.py --compiler .tools/tectonic.exe --output output/reproduced-comparison
```
